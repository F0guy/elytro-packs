# elytro-packs

Resource packs for the Elytro Minecraft server. Players reach the server
through Minehut, whose proxy only lets packs through from allowed hosts
(GitHub raw is one), so the packs are served from here.

- `elytro-boss-pack.zip` - ElyBosses' pack (BetterModel boss models, boss
  sounds, merchant fonts, orange Hallows gate portal + particles). ElyBosses
  builds it on the server and offers players this file with its own SHA-1,
  so this copy must match the server's build byte for byte. Re-sync after
  any boss/pack change.
- `elytro-emojis.zip` - ElyEmojis chat emoji glyphs. Its SHA-1 lives in
  plugins/ElyEmojis/config.yml.
